# Hay Day Daku Cello – Daftar Harga

Website katalog interaktif dan pemesanan WhatsApp untuk Hay Day Daku Cello.

## Fitur
- 🛒 Katalog item Hay Day per kategori (Alat & Bahan, Dapur & Peternakan, Laut, Tambang, dll)
- 🧮 Kalkulator total otomatis
- 📋 Salin daftar pesanan ke clipboard
- 💬 Tombol pesan langsung terhubung ke WhatsApp

## Deploy ke Vercel

### Opsi 1: Lewat Git (GitHub / GitLab / Bitbucket)
1. Push folder proyek ini ke repositori GitHub.
2. Buka dashboard [vercel.com](https://vercel.com).
3. Klik **Add New...** -> **Project**.
4. Import repositori Anda dan klik **Deploy** (Vercel otomatis mendeteksi `index.html`).

### Opsi 2: Menggunakan Vercel CLI
Jalankan perintah berikut di terminal:
```bash
npx vercel
```
Ikuti instruksi di layar, dan web akan langsung online.
